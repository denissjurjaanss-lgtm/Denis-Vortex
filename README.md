# 🎯 Vortex SWAT Manager

Profesionāla desktop aplikācija SWAT komandas pārvaldībai un organizācijai.

## ✨ Galvenās Funkcijas

- **Reģistrācija & Autentifikācija** - Drošs lietotāju kontu sistēma
- **Chief Panelis** - Pilna kontrole pār komandu (tikai Chief)
- **Pieteikumu Apstiprināšana** - Jaunieskrējušos locekļu pārvaldība
- **Rangu Vadība** - SWAT rangu piešķiršana un pārvaldība
- **Brīdinājumu Sistēma** - Disciplināras darbības reģistrēšana
- **Biedru Meklēšana** - Ātrs biedru atrašanas rīks
- **Tumšais SWAT Dizains** - Profesionāls militāro stilu konts

## 🚀 Instalācija

```bash
git clone https://github.com/denissjurjaanss-lgtm/Denis-Vortex.git
cd Denis-Vortex
npm install
npm start
```

## 💻 Tehnoloģijas

- **Electron** - Desktop aplikāciju framework
- **React** - UI komponentu bibliotēka
- **CSS3** - Moderns stilizēšanas
- **JavaScript (ES6+)** - Programmatūra valoda
